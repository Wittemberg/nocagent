# Regras de Interface Clean (Modo Claro)

Sempre que projetar, construir ou revisar estilos para o modo claro (Light Mode), as seguintes características **devem** ser seguidas para garantir uma interface clean e agradável aos olhos:

## 1. Fundo Suave (Redução de Cansaço Visual)
- **Evite o branco puro (`#FFFFFF`)** em áreas muito grandes. O branco puro reflete muita luz e causa cansaço visual, parecendo uma tela "simples" e inacabada.
- **Use tons muito claros de cinza ou azulado** (ex: `#F8F9FA`, `slate-50`, `slate-100`) para quebrar a intensidade da luz no fundo principal (background) da aplicação.
- Cartões e contêineres em destaque podem usar `#FFFFFF` para gerar um contraste suave de elevação em relação ao fundo macio.

## 2. Hierarquia Visual (Textos)
- **Nunca use preto puro (`#000000`)** ou quase-preto (`#0f172a`) como padrão absoluto para textos longos ou listas.
- **Use tons de cinza escuro ou grafite** (ex: `#334155` - `slate-700`, `#475569` - `slate-600`) para textos principais. Isso cria uma leitura muito mais natural e menos agressiva.
- Textos de suporte e metadados devem ser ainda mais sutis (`slate-500` ou `slate-400`).

## 3. Espaçamento (White Space)
- **Deixe os elementos "respirarem"**. O segredo de uma interface limpa é o equilíbrio dos espaços vazios ao redor dos componentes.
- Aumente margens e paddings entre seções para evitar que a interface pareça densa e sufocante.
