# Stage 28 — Sales Guide

## Elevator pitch
> InfraOps AI foi projetado para pequenos prestadores de TI que precisam organizar e cuidar de vários clientes sem depender de planilhas, memória ou uma equipe grande. A plataforma mostra o que precisa de atenção, orienta a configuração e oferece profundidade técnica quando necessário.

## Core objection
“Parece poderoso demais para mim.”

Response:
> A plataforma possui recursos avançados, mas o uso diário é organizado em linguagem simples. O Modo Técnico existe para quem quiser aprofundar. O objetivo é você crescer sem precisar trocar de ferramenta.

## Demo flow
1. Início — mostrar prioridades do dia.
2. Clientes — abrir um cliente.
3. Resumo — saúde, backups, Internet, equipamentos.
4. Assistente — perguntar “como está este cliente?”.
5. Aprovação — mostrar uma ação humanizada.
6. Relatórios — provar valor do serviço.

## Key sales lines
- “Menos planilha. Mais controle.”
- “Profissionalize sua operação sem montar um NOC.”
- “Simples para começar, completo para crescer.”
- “Toda a infraestrutura dos seus clientes em um só lugar.”
- “Infraestrutura sob controle. Inteligência para agir.”
