# ADR-015 — IA não é Dependência do Core

## Status

Accepted

## Contexto

InfraOps AI administra infraestrutura potencialmente crítica e deve preservar segurança, isolamento, rastreabilidade e capacidade de evolução.

## Decisão

Monitoramento, alerts, backup evaluation e automações determinísticas continuam funcionando sem o provedor de IA.

## Consequências

Reduz risco operacional e vendor lock-in.
