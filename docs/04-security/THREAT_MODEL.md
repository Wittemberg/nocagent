# Threat Model — Skeleton

Este documento será detalhado antes da primeira implantação com Actions privilegiadas.

Ameaças obrigatórias a modelar:

- central comprometida;
- agent comprometido;
- stolen enrollment/agent token;
- malicious tenant user;
- cross-tenant access;
- prompt injection;
- dependency/supply-chain compromise;
- MITM/replay;
- log poisoning;
- approval replay;
- privilege escalation local;
- secret leakage.
