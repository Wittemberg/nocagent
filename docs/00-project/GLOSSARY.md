# Glossário

- **Action**: operação permitida, tipada, versionada e executada por executor conhecido.
- **Agent**: serviço instalado no node que coleta dados e executa Actions autorizadas.
- **Actor**: usuário, IA, agent, sistema ou integração que origina/interage com uma operação.
- **Approval**: autorização humana para execução de um Job quando exigida.
- **Backup Artifact**: cópia de backup descoberta/registrada pela plataforma.
- **Backup Expectation**: ocorrência de backup esperada para uma janela/policy.
- **Job**: instância de uma Action solicitada para um target.
- **Node**: host físico/virtual monitorado.
- **Policy Engine**: componente que decide `allow`, `deny` ou `require_approval`.
- **Resource Lock**: bloqueio compartilhado/exclusivo que evita operações conflitantes.
- **Tenant**: cliente/organização isolada dentro da plataforma.
- **Workload**: VM, container ou VPS executado em um node/hypervisor.
