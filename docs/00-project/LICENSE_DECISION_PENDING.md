# Decisão de Licenciamento Pendente

A licença do InfraOps AI ainda não foi definida.

Antes da primeira distribuição pública/comercial, decidir explicitamente se o projeto será:

- proprietário;
- source-available;
- open source (e sob qual licença);
- modelo híbrido/open-core.

Não adicionar uma licença por conveniência sem analisar impacto comercial, uso de contribuições e distribuição do Agent.
